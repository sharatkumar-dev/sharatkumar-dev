## 🧩 Selected Work

### 🤝 [Bharat Sathi AI](https://github.com/sharatkumar-dev/bharat-sathi-ai-2.0)
A multilingual opportunity assistant that helps students discover and understand scholarships, internships, education loans, and skills opportunities.

**Built with:** React, TypeScript, Vite, Tailwind CSS, Google Gemini, Zod, Vitest

**Highlights:** Deterministic eligibility matching, grounded multilingual AI chat, client-side PII masking, document explanation, and safety-focused architecture.

---

### 💼 [Indian Presumptive Tax Assistant](https://github.com/sharatkumar-dev/Capstone-Project)
A multi-agent AI assistant for presumptive tax calculations under Sections 44ADA and 44AD.

**Built with:** Python, Streamlit, Gemini, Pydantic, Docker

**Highlights:** Specialized Router, Vision, and Calculator agents, multimodal invoice/receipt processing, statutory limit checks, report generation, and API fallback handling.

---

### 🛒 [NexisStore](https://github.com/sharatkumar-dev/SkillNexis-MERN-Stack-Internship)
A full-stack MERN e-commerce storefront developed as the capstone project of my SkillNexis Full Stack Web Development internship.

**Built with:** React, Vite, Node.js, Express, MongoDB, Mongoose, JWT

**Highlights:** Authentication, product and task-style CRUD patterns, image uploads, persistent cart functionality, REST APIs, testing, and cloud deployment.

🌐 [Live Storefront](https://nexisstore.netlify.app/)

---

### ☁️ [BigQuery Release Notes Explorer](https://github.com/sharatkumar-dev/bigquery-release-notes-app)
A focused web app that turns official Google Cloud BigQuery release notes into searchable, categorized updates.

**Built with:** Python, Flask, HTML, CSS, JavaScript

**Highlights:** Live Atom feed integration, granular update parsing, category filtering, keyword search, responsive dark UI, and an X/Twitter composer with automatic character-limit handling.
